Добро пожаловать в программу установки Научного калькулятора!

ОПИСАНИЕ:
Научный калькулятор - это веб-приложение с полным набором 
математических функций, разработанное в рамках учебного проекта 
по изучению Git и unit-тестирования.

ФУНКЦИОНАЛЬНОСТЬ:
✓ 12 математических операций
✓ Тригонометрические функции (sin, cos)
✓ Возведение в степень и извлечение корня
✓ Округление (floor, ceil)
✓ Работа с памятью (M+, MC, MR)
✓ Современный интерфейс

СИСТЕМНЫЕ ТРЕБОВАНИЯ:
- Операционная система: Windows 7/8/10/11
- Веб-браузер: Chrome, Firefox, Edge или Safari
- Место на диске: ~500 KB
- Дополнительно: не требуется

УСТАНОВКА:
1. Выберите папку для установки (по умолчанию: Program Files)
2. Выберите компоненты для установки
3. Дождитесь завершения установки
4. Запустите калькулятор из меню Пуск или с рабочего стола

ИСПОЛЬЗОВАНИЕ:
После установки калькулятор откроется в вашем браузере по умолчанию.
Вы можете использовать его как обычное веб-приложение.
