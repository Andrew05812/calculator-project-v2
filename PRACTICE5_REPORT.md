## Непрерывная интеграция (теория)

### Что такое CI/CD?

**CI (Continuous Integration)** - непрерывная интеграция:
- Частое слияние кода в общую ветку
- Автоматическая сборка
- Автоматическое тестирование
- Раннее обнаружение ошибок

**CD (Continuous Delivery/Deployment)** - непрерывная доставка:
- Автоматическое создание релизов
- Автоматическое развертывание
- Быстрая доставка функций пользователям

### Преимущества CI/CD:

1. **Раннее обнаружение ошибок** - тесты запускаются автоматически
2. **Быстрая обратная связь** - результаты сборки за минуты
3. **Уменьшение рисков** - небольшие частые изменения
4. **Улучшение качества** - постоянное тестирование
5. **Автоматизация** - меньше ручной работы
6. **Предсказуемость** - стандартный процесс

