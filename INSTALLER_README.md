## 🎯 Описание установщика

Установочный пакет для **Научного калькулятора v3.0** создан с использованием **Inno Setup 6**.

### Параметры установщика:

| Параметр | Значение |
|----------|----------|
| Тип пакета | Windows Setup (.exe) |
| Инструмент | Inno Setup 6 |
| Размер | ~500 KB - 1 MB |
| Архитектура | x64 compatible |
| Сжатие | LZMA (максимальное) |
| Языки | Русский, English |

## 📋 Системные требования

### Минимальные требования:
- **ОС:** Windows 7 / 8 / 10 / 11
- **Браузер:** Chrome, Firefox, Edge, Safari (любой современный)

## 🚀 Процесс установки

### Шаг 1: Запуск установщика
1. Скачайте `ScientificCalculator-Setup-v3.0.exe`
2. Двойной клик по файлу
3. Выберите язык (Русский/English)

### Шаг 2: Выбор компонентов
- ✅ Основные файлы приложения (обязательно)
- ☐ Создать значок на рабочем столе (опционально)
- ☐ Создать ярлык быстрого запуска (опционально)

### Шаг 3: Выбор папки установки
- По умолчанию: `C:\Program Files\ScientificCalculator`
- Можно изменить на любую другую папку

### Шаг 4: Установка
- Автоматическое копирование файлов
- Создание ярлыков
- Регистрация в системе

### Шаг 5: Завершение
- ✅ Запустить калькулятор сразу после установки
- ✅ Открыть документацию

## 🔨 Сборка установщика (для разработчиков)

### Требования:
- Inno Setup 6 (https://jrsoftware.org/isdl.php)
- Файлы проекта в папке `dist/app/`

### Команды для сборки:
```powershell
# Подготовка файлов
mkdir dist\app
Copy-Item index.html, style.css, calculator.js, script.js dist\app\

# Компиляция (через Inno Setup)
# Правой кнопкой по installer.iss → Compile
# ИЛИ через командную строку:
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

### Результат:
- Файл установщика в папке `output/`
- Имя: `ScientificCalculator-Setup-v3.0.exe`

## 🐛 Решение проблем

### Проблема: Установщик не запускается
**Решение:** Проверьте наличие прав на запуск .exe файлов

### Проблема: Калькулятор не открывается
**Решение:** Убедитесь, что установлен браузер по умолчанию

### Проблема: Отсутствует иконка
**Решение:** Пересоберите с файлом icon.ico в папке dist/

### Проблема: Ошибка при удалении
**Решение:** Удалите папку `C:\Program Files\ScientificCalculator` вручную
