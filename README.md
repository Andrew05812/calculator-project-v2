## ✨ Функциональность

### Базовые операции (Разработчик 1)
1. ➕ **Сложение** - выполняет сложение двух чисел
2. ➖ **Вычитание** - выполняет вычитание
3. ✖️ **Умножение** - выполняет умножение
4. ➗ **Деление** - выполняет деление (с защитой от деления на ноль)
5. ➗ **Остаток от деления** - вычисляет остаток (оператор %)
6. 📐 **Sin** - вычисляет синус угла в градусах

### Продвинутые функции (Разработчик 2)
7. 📐 **Cos** - вычисляет косинус угла в градусах
8. 🔺 **Возведение в степень** - возводит число в степень (x^y)
9. √ **Квадратный корень** - извлекает квадратный корень
10. ⌊ **Округление вниз (floor)** - округляет к меньшему целому
11. ⌈ **Округление вверх (ceil)** - округляет к большему целому
12. 💾 **Работа с памятью** - функции M+ (добавить в память), MC (очистить память), MR (вызвать из памяти)

## 🎨 Интерфейс

Калькулятор имеет современный дизайн с:
- Градиентным фоном
- Адаптивной сеткой кнопок (5 колонок)
- Цветовой кодировкой кнопок:
  - 🔵 Синие - операторы (+, -, ×, ÷, %, x^y)
  - 🟣 Фиолетовые - математические функции (sin, cos, √, floor, ceil)
  - 🟢 Зеленые - работа с памятью (M+, MC, MR)
  - 🔴 Красная - вычисление результата (=)
  - ⚪ Серые - цифры и вспомогательные кнопки

## 📝 Примеры использования

### Базовые операции:
```
5 + 3 = 8
10 - 4 = 6
6 × 7 = 42
20 ÷ 4 = 5
10 % 3 = 1
```

### Тригонометрия:
```
30 sin = 0.5
60 cos = 0.5
```

### Продвинутые функции:
```
2 x^y 3 = 8 (возведение в степень)
16 √ = 4 (квадратный корень)
3.7 ⌊x⌋ = 3 (округление вниз)
3.2 ⌈x⌉ = 4 (округление вверх)
```

### Работа с памятью:
```
1. Введите 5
2. Нажмите M+ (сохранить в память)
3. Очистите дисплей (C)
4. Нажмите MR (вызвать из памяти) → вернётся 5
5. Нажмите MC (очистить память)
```
