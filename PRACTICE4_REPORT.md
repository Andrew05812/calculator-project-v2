### 4. Создание скрипта установщика (installer.iss)

**Основные параметры:**

| Параметр | Значение |
|----------|----------|
| AppName | Научный калькулятор |
| AppVersion | 3.0 → 4.0 |
| AppPublisher | andrew05812 & BuMcHiKa |
| DefaultDirName | {autopf}\ScientificCalculator |
| Compression | LZMA (максимальное сжатие) |
| Languages | Русский, English |
| Архитектура | x64 compatible |

**Секции скрипта:**

#### [Setup]
Основные параметры установщика:
- Имя приложения
- Версия
- Издатель
- Папка установки по умолчанию
- Параметры сжатия
- Стиль мастера установки

#### [Languages]
Поддержка двух языков:
- Русский (по умолчанию)
- English

#### [Files]
Список устанавливаемых файлов:
- Основные файлы приложения (HTML, CSS, JS)
- Документация (README, отчёты)
- Ресурсы (иконки)
- Лицензия

#### [Icons]
Создание ярлыков:
- В меню Пуск
- На рабочем столе (опционально)
- В быстром запуске (опционально)

#### [Run]
Действия после установки:
- Запуск приложения (опционально)
- Открытие документации

#### [Code]
Дополнительный код на Pascal Script:
- Проверка системных требований
- Проверка наличия браузера
